# 拾光茶舖｜線上點餐系統

🍵 一款清新簡約、體驗流暢的線上飲料點餐系統（Single Page Application）。

## ✨ 功能特色

- **豐富茶單分類**：純茶、奶茶、果茶等分類即時切換與關鍵字搜尋
- **客製化規格**：自由選擇杯型（中杯 / 大杯）、甜度（無糖～全糖）、冰量（去冰～熱飲）與數量
- **即時購物車**：自動計算總計金額、支援增減數量與移除品項
- **取餐訂購表單**：填寫姓名、電話、取餐時間與備註，自動生成訂單編號
- **RWD 響應式設計**：完美支援手機、平板與桌機各尺寸螢幕

## 🚀 部署說明

本專案為純前端單頁應用（SPA），可直接透過 **GitHub Pages** 託管：
1. 將專案推送到 GitHub Repository。
2. 進入 Repository 的 **Settings** > **Pages**。
3. 在 **Branch** 選擇 `main` 分支並指定根目錄 `/ (root)`，點擊 **Save**。
4. 稍等約 1~2 分鐘即可透過 `https://<你的GitHub帳號>.github.io/<儲存庫名稱>/` 瀏覽。
